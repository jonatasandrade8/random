7. Teste: "o jogo sugerido acerta mais que o acaso?"

Aqui é o teste honesto: para cada concurso passado, o sistema gera X jogos com a estratégia e X jogos aleatórios (mesma semente), e compara os acertos. O teste é feito em várias escalas (1, 2, 3, 5, 10, 20, 50 jogos) para ver se o efeito aparece em alguma.

(para base completa ~3800, use 1000–1500)
